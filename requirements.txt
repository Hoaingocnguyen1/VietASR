### Quy trình làm việc của bạn với Docker

1.  Tạo file `Dockerfile` như trên trong thư mục gốc của dự án.
2.  Tạo file `requirements.txt` như trên.
3.  Viết code cho API của bạn (ví dụ: `api_server.py`).
4.  Mở terminal trong thư mục dự án và chạy lệnh **build**:
    ```bash
    docker build -t my-asr-api .
    ```
    Lệnh này sẽ đọc `Dockerfile` và thực hiện từng bước để tạo ra một "image" tên là `my-asr-api`. Quá trình này có thể mất nhiều thời gian trong lần đầu tiên.

5.  Sau khi build xong, bạn có thể chạy API của mình bằng lệnh **run**:
    ```bash
    # Chạy container, ánh xạ cổng 8000 của container ra cổng 8000 của máy bạn
    # --gpus all là bắt buộc để container có thể sử dụng GPU
    docker run -p 8000:8000 --gpus all my-asr-api
    ```

**Kết luận:** Bạn không chỉ "cần" làm requirements, mà bạn phải **tự động hóa toàn bộ quá trình cài đặt phức tạp** đó vào trong một `Dockerfile`. Đây là sức mạnh và cũng là yêu cầu cốt lõi khi làm việc với Docker.
